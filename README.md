# وصلني توكتوك — V5.2.3

منصة حجز توكتوك لسيدي سالم، مبنية على Android + Firebase، مع فصل واضح بين الراكب والسائق والإدارة.

## ما تم تطويره في V5.1

- تسجيل المستخدمين برقم هاتف موثق عبر SMS بدل الحسابات المجهولة.
- دورة الرحلة كاملة: بحث → عروض → اختيار → في الطريق → وصل → بدأت → انتهت.
- مطابقة سائقين Server-side عبر Firebase Cloud Functions.
- توسيع البحث: 500م → 1كم → 2كم → 5كم.
- حجز مدارس/حجز مسبق بحالة `scheduled` وتشغيل البحث تلقائيًا وقت الموعد.
- إشعارات Push للراكب والسائق عند الطلب والعرض والقبول وحالات الرحلة.
- تقييم متبادل بعد انتهاء الرحلة مع منع التقييم المكرر.
- سائقون معتمدون فقط يدخلون نظام استقبال الرحلات.
- حالة السائق متاح/غير متاح مع تحديث الموقع في الخلفية.
- متابعة موقع السائق لحظيًا أثناء الرحلة.
- صلاحيات Firestore مقيدة حسب الدور والحالة.
- إدارة طلبات السائقين من لوحة المشرف.
- GitHub Actions لفحص وبناء Android وCloud Functions.
- تنظيف أسرار التوقيع وعدم تضمين ملفات keystore في Git.

## ميزات V5.2.2

- أفضل خمسة عروض للراكب وإغلاق طلبات السائقين الآخرين عند قبول عرض.
- اشتراك السائق: 100 جنيه لأول شهر و200 جنيه للتجديد، مع إثبات تحويل مصور خاص يراجعه المشرف.
- طلب السائق يرفع صور البطاقة والمركبة إلى Storage خاص؛ الصورة الشخصية اختيارية، والمشرف يعاين الصور قبل الاعتماد.
- فرض الاشتراك النشط على ظهور السائق وقبوله للعروض، وإحصاءات السائق والراكب.
- إيقاف طلب الرحلات 24 ساعة بعد أكثر من 3 إلغاءات في اليوم.
- لوحة المشرف: السائقون واستكمال البيانات والاشتراكات والرحلات والتقييمات.
- موافقة شروط مؤرخة لكل حساب وزر طلب رحلة مباشر للراكب.

تُحوّل رسوم الاشتراك إلى 01069631950. الشروط الحالية صياغة تشغيلية أولية وتحتاج اعتمادًا قانونيًا ومراجعة سياسة الخصوصية قبل الإطلاق العام.

## تحديثات V5.2.3

- تحسين اختيار موقعي الانطلاق والوجهة على الخريطة ومعالجة إذن الموقع.
- بدء البحث عن الرحلات الفورية من الخادم أيضًا، مع منع تشغيل عاملَي بحث للرحلة نفسها.
- إرسال الحجز المدرسي/المسبق للسائقين المتاحين ذوي الاشتراك النشط عند موعده، مستقلًا عن نطاقات البحث الفوري.
- التحقق من الإحداثيات ونوع الحجز، وتقسيم كتابة طلبات السائقين إلى دفعات آمنة لـFirestore.
- تحديث موقع السائق عبر `heartbeatDriver` وإيقاف إتاحته بعد انتهاء الاشتراك.
- إتاحة دخول المشرف من شاشة الحساب مع استمرار التحقق عبر Firebase Authentication ووثيقة `admins/{UID}`.
- رقم الإصدار: `versionCode 10`، `versionName 5.2.3`.

## المجلدات

- `app/` تطبيق Android.
- `functions/` Backend للمطابقة والحجوزات والإشعارات.
- `firestore.rules` قواعد الأمان.
- `firestore.indexes.json` الفهارس المطلوبة.
- `.github/workflows/` فحص وبناء المشروع.

## تشغيل Android

```bash
./gradlew assembleDebug
```

## تشغيل Backend

```bash
cd functions
npm ci
npm run lint
npm run build
```

ثم من جذر المشروع:

```bash
firebase use wasalny-app-f5dbb
firebase deploy --only firestore:rules,firestore:indexes,storage,functions
```

فعّل Firebase Storage وأنشئ bucket للمشروع قبل رفع صور التحويل. الإيصالات خاصة ولا تتجاوز 5 ميجابايت؛ راجع `DEPLOY_FIREBASE_AR.md` لخطوات النشر.

## متطلبات الإنتاج

- فعّل Phone Authentication في Firebase.
- فعّل Cloud Functions وCloud Scheduler؛ الحجز المسبق والإشعارات يعتمد عليهما.
- استخدم خطة Blaze لـ Firebase Functions/Scheduler وفق إعدادات مشروعك.
- يحتاج البناء المتصل بمشروع Firebase إلى إعداد العميل الصحيح في `app/google-services.json`، أو إلى GitHub Secret باسم `GOOGLE_SERVICES_JSON` يحتوي الملف بترميز Base64. يستخدم CI إعدادًا تجريبيًا بديلًا عند غياب السر؛ لا تستخدمه لتطبيق الإنتاج.
- أضف رقم/حساب المشرف إلى مجموعة `admins` بصلاحية `role=admin` و`active=true`.
- اختبر التطبيق على جهازين حقيقيين: راكب + سائق، قبل الإطلاق العام.
- الدفع الإلكتروني غير مفعّل؛ الرحلات الحالية تعتمد على الأجرة النقدية المتفق عليها.

## حالة الاختبار

نجحت أوامر `npm ci` و`npm run build` و`npm run lint` لوظائف Cloud Functions، ونجح `./gradlew lintDebug assembleDebug` باستخدام Java 21 وAndroid SDK API 35. lint بلا أخطاء؛ وتبقى تنبيهات اختيارية لإصدارات أحدث من بعض المكتبات. الناتج Debug APK في `app/build/outputs/apk/debug/app-debug.apk`، بإصدار `5.2.3` ورقم `10`؛ وهو موقّع بمفتاح debug وليس إصدارًا موقّعًا للنشر. تم التحقق من ملفات Firebase JSON، لكن لم يتم نشر Firebase أو اختبار تدفقات التطبيق على جهاز حقيقي؛ تعذر تشغيل المحاكي بسبب صلاحيات KVM في بيئة البناء.

راجع `AUDIT_REPORT_AR.md` و`PRODUCTION_ARCHITECTURE_AR.md` قبل النشر.
